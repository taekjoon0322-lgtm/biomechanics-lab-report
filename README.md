# 합성 고분자 가공과 PUA 플레이트 제작

최신 제출본: [합성_고분자_가공과_PUA_플레이트_제작_20쪽_최종본.docx](합성_고분자_가공과_PUA_플레이트_제작_20쪽_최종본.docx)

팀원 보고서의 제목과 양식을 유지하고 기존 보고서의 공정 설명, 사진, 기포 제거 경험과 고찰을 통합했다. 표지·목차·참고문헌을 포함해 총 20쪽으로 확인했다.

- 실제 제작: MINS-311RM과 PET, 패턴이 없는 플랫 웨이퍼를 이용한 PUA 필름.
- 관찰 경험: 실험 전부터 깨진 원판 가장자리에서 기포 제거가 어려웠음.
- 탈형 이후: 약 24시간 안정화로 표현. 추가 UV 조사로 단정하지 않음.
- 나노패턴: 수업에서 소개된 비교용 시편과 원리 설명으로 구분.
- 편집: 목차는 일반 텍스트로 편집 가능하며 페이지 번호는 최종 배치에 맞춤.

[본문과 사진 보기](report.md) · [통합본 사진 및 도식](media/integrated-20page/)

표지 오른쪽 상단 및 본문 머리말의 전남대학교 로고를 유지했다. 기존 버전은 작성 이력으로 남겨 두었으며, 제출에는 위 최신 통합본을 사용한다.
