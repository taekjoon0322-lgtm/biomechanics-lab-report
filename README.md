이론은 문헌을 바탕으로 설명하고, 실제 실험값과 측정하지 않은 결과는 추정해서 채우지 않았습니다.

상세 수정본은 표지 입력란과 목차를 일반 문단으로 만들고, 떠 있는 개체와 텍스트 상자를 제거했습니다. 표지의 회색 대괄호 문구를 선택하여 교체할 수 있습니다. 목차도 직접 수정할 수 있는 텍스트이며, 본문 길이를 바꾸면 목차의 쪽수도 함께 조정해야 합니다. 본문에는 Word 제목 스타일을 적용했습니다.

세부 목차 31개 항목, 광중합 원리와 조사량 관계, 패턴 복제 단면, 제작 공정, 접촉 결함, 회절 원리를 보강했습니다. 그림의 가상 형상과 계산 조건은 실제 실험 측정값과 구분했습니다.
