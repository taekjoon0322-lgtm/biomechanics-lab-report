## 추가 확인사항

- 실제 사용 수지: MINS-311RM (사용자 확인 완료)
- UV 경화기의 40.0 표시 단위 및 실제 조사 시간
- 메모의 5–10분이 UV 조사 시간인지 조사 후 대기 시간인지
- 건조 대상, 건조 시간 및 실제 실험일
- 사진 003–005가 소개용 기존 시편인지 이번 제작 시편인지

영상이 있으면 수지 도포·PET 적층 순서와 탈형 동작을 더 자세히 확인할 수 있습니다. 배속·편집 여부가 확인되지 않은 영상으로 경화 시간을 계산하지 않습니다.
