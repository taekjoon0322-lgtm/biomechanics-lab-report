# 제출 전 추가 확인사항

- 표지: 과목명, 담당교수, 제출일, 학과, 학번, 이름
- UV 경화기 40.0의 단위와 실제 조사 시간; 메모 5–10분이 해당하는 단계
- 건조 대상과 건조 시간; PET 두께와 원판 패턴 규격
- 가능하면 실제 완성 시편의 근접 사진. 수지 도포 또는 UV 타이머 조작 영상이 있으면 공정 확인에 유용함

추가 사진 30장을 검토함. 실리콘 A·B 용기 및 MINS-311RM 라벨 사진을 본문에 추가함. SEM·AFM은 나노패턴 치수나 복제 품질을 정량적으로 주장할 때 필요한 자료이며 현재 보고서는 해당 측정을 수행했다고 쓰지 않음.

## 표지와 목차 편집

최신 상세 수정본에서는 표지와 목차를 모두 일반 문단으로 다시 만들었습니다. 이전 파일 대신 상세 수정본을 열고 표지의 회색 대괄호 문구를 선택해 교체합니다. 떠 있는 도형, 텍스트 상자와 편집 보호 설정은 없습니다. 목차는 직접 수정하는 텍스트이므로 본문 길이를 바꾸면 쪽수도 조정해야 합니다. 파란 화살표는 서식 표시입니다.

UV 타이머 조작 또는 수지 도포 영상이 있으면 조사 시간의 단위와 도포 순서를 확인하는 데 도움이 됩니다. 완성 시편의 동일 영역을 여러 각도에서 촬영하면 외관과 손상을 비교하기 쉽습니다.
