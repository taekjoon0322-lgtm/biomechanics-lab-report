# 10월 15일 실험일지 — 혼합·탈포·열경화

> 사용자 메모를 바탕으로 정리한 기록. 재료명·경화 조건은 추후 확인.

## 목적

두 재료를 10:1 질량비로 혼합하고 진공 탈포와 열경화를 거쳐 시편을 제작한다.

## 실험 과정

| 단계 | 작업 내용 |
| --- | --- |
| 1. 준비·소독 | 작업 공간과 도구를 깨끗하게 소독하고, 흘림에 대비해 작업대에 티슈를 깐다. |
| 2. 영점 설정 | 혼합 용기를 저울에 올리고 영점을 맞춘다. |
| 3. 계량 | 처음에는 10~20 g 범위를 생각했으나 실제 첫 번째 재료는 **9 g**을 계량했다. 두 번째 재료는 **0.9 g**으로 맞춰 **10:1**, 총 **9.9 g**을 준비했다. |
| 4. 혼합 | 약 **200회** 저어 충분히 섞었다. 메모에는 기포가 많이 생길 때까지 저은 것으로 기록되어 있다. 발생한 기포는 다음 탈포 단계에서 제거한다. |
| 5. 진공 탈포 | 혼합물을 진공 챔버에 넣고 기포를 제거한다. 기포가 팽창해 넘치지 않도록 상태를 보면서 공기를 조절한다. 이후 챔버에서 꺼낸다. |
| 6. 붓기 | 준비된 용기 또는 몰드에 혼합물을 붓고, 남은 기포를 터뜨려 제거한다. |
| 7. 열경화 | 열을 가해 굳힌다. 경화 온도와 시간은 미기록이다. |

## 관찰·설명 메모

- 진공 챔버에서 꺼낸 상태와 잔여 기포를 터뜨리는 장면을 사진 연결 대상으로 남긴다.
- 경화된 시편 위에 세포를 배양할 수 있다는 설명을 들었다. 실제 배양에 필요한 표면 처리와 멸균 조건은 추후 확인한다.
- ‘영구적으로 이용 가능’이라는 설명을 메모했으나, 재사용 횟수와 조건은 확인되지 않았다.
